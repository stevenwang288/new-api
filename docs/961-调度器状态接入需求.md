# 961 调度器状态接入需求

## 一、目标

在 961 上运行的 NewAPI 管理界面中，增加 961 本机 dispatcher 的运行状态展示。

管理员编辑渠道时，应能看到 dispatcher 总体状态，以及 12 个 lane 的请求统计、成功统计、错误统计、暂停状态和冷却状态，并能够自动刷新。

本需求的最终业务目标是：管理员不需要登录 961 服务器或查看容器日志，就能在 NewAPI 渠道编辑界面判断 12 个 lane 是否正常工作。

## 二、机器和组件职责

### 1. 961 服务器

961 是本需求的目标服务器，地址为 `192.168.9.61`。

961 上运行两类服务：

- `new-api-961`：本需求要改造和替换的 NewAPI 实例，监听 `3000` 端口。
- `opencode-zen-dispatcher`：提供 12 个 lane 的请求分发和状态接口，监听 `4010` 端口。

dispatcher 状态接口为：

```text
http://127.0.0.1:4010/status
```

### 2. PVE 宿主机

PVE 宿主机 `192.168.9.250` 只是 SSH 转发入口，不是业务部署目标。通过它连接 961 时，必须确认最终远端主机是 `192.168.9.61`。

## 三、数据流

状态读取链路必须是：

```text
管理员浏览器
    -> 961 NewAPI:3000/api/channel/dispatcher/status
    -> 961 dispatcher:4010/status
    -> 961 NewAPI 返回状态
    -> 管理界面展示
```

浏览器不能直接请求 dispatcher。NewAPI 后端负责代理请求，并在后端执行管理员身份和渠道读取权限检查。

默认 dispatcher 地址为：

```text
http://192.168.9.61:4010/status
```

如需覆盖地址，应使用环境变量 `DISPATCHER_STATUS_URL`，不得把浏览器端地址写死成跨服务直连请求。

## 四、代码要求

### 1. 后端

新增受保护的接口：

```text
GET /api/channel/dispatcher/status
```

要求：

- 必须经过管理员身份验证。
- 必须经过 `ChannelRead` 权限验证。
- 请求 dispatcher 的超时、连接失败和非 2xx 响应必须返回明确错误。
- 不得把 dispatcher 的内部地址暴露为浏览器跨域请求目标。
- 返回 dispatcher 的状态数据，至少包含总体状态和 lane 列表。

### 2. 前端

在渠道编辑器的高级设置区域增加 dispatcher 状态面板。

每个 lane 至少展示：

- lane 名称。
- 请求总数。
- 成功数。
- 错误数。
- 暂停或可用状态。
- 冷却剩余状态或 ready 状态。

要求：

- 面板打开后每 5 秒刷新一次。
- 加载中显示稳定的加载状态。
- dispatcher 不可用时显示错误状态，不得让整个渠道编辑器崩溃。
- 使用项目现有的 API 请求封装和国际化方式。
- 不得直接从浏览器访问 `192.168.9.61:4010`。

## 五、961 部署要求

### 1. 构建对象

必须使用改造后的后端二进制和前端 `web/dist` 构建新的运行时镜像：

```text
new-api-961:lane-observability
```

镜像必须以现有 `calciumion/new-api:latest` 为运行时基础，并覆盖：

- `/new-api`：改造后的 Linux amd64 后端二进制。
- `/web/dist`：改造后的前端生产构建产物。

后端二进制必须具有可执行权限。

### 2. 替换对象

只替换 961 上的：

```text
new-api-961
```

替换时必须保留：

- 容器名 `new-api-961`。
- 端口映射 `3000:3000`。
- Docker 网络 `new-api-961_default`。
- 数据挂载 `/opt/new-api-961/data:/data`。
- 重启策略 `unless-stopped`。

数据库和数据目录不得删除、覆盖或迁移。

### 3. Compose 持久化

`/opt/new-api-961/docker-compose.yml` 必须使用改造镜像：

```yaml
services:
  new-api-961:
    image: new-api-961:lane-observability
    container_name: new-api-961
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - /opt/new-api-961/data:/data
```

不能只手工 `docker run` 而保留 Compose 中的官方镜像，否则下次重启或 `docker compose up` 会把改造版本覆盖回旧版本。
